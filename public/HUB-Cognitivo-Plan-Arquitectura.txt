1. VISIÓN Y PROPÓSITO


El HUB Cognitivo de Prospección es una aplicación web privada que centraliza en una sola interfaz todas las actividades de prospección, seguimiento, campañas y gestión de clientes de Desarrollos Elaborados e iAprende. Opera como el sistema nervioso central de ventas y marketing, potenciado con agentes de IA que automatizan tareas repetitivas, generan contenido, califican prospectos y orquestan acciones en múltiples canales.


Principio rector — Skin in the Game Digital
Todo flujo se valida primero en operación real de Desarrollos Elaborados y Corte & Diseño CNC antes de ofrecerse como producto SaaS a otros talleres o agencias.
	

Problema que resuelve


* Prospección dispersa entre WhatsApp, correo, DMs y Facebook
* Sin pipeline visual ni seguimiento automatizado
* Campañas de email/newsletter sin herramienta propia
* Ideas y proyectos internos sin trazabilidad
* Cero visibilidad de métricas de conversión
	Qué entrega el HUB


* Pipeline CRM unificado con etapas configurables
* Bandeja unificada de mensajes multi-canal
* Motor de newsletters y campañas masivas
* Gestión de proyectos e ideas con scoring IA
* Dashboard de métricas en tiempo real
	

2. ARQUITECTURA DE MÓDULOS


El HUB se organiza en 8 módulos funcionales interconectados. Cada módulo tiene su propia sección en la barra lateral y comparte una base de datos centralizada en Firebase/Supabase.


01
	PROSPECCIÓN — Pipeline CRM
Gestión visual de leads por etapa: Nuevo › Contactado › Calificado › Propuesta › Cierre › Ganado/Perdido. Vista Kanban + Lista + Timeline.
	

02
	COTIZACIONES & CURSOS
Generador de propuestas parametrizadas para servicios CNC, automatización, cursos iAprende y proyectos de ingeniería. Firma digital y seguimiento.
	

03
	PROYECTOS & IDEAS
Repositorio de iniciativas internas con scoring IA (impacto, esfuerzo, alineación estratégica). Estados: Idea › Evaluación › Activo › Pausado › Completado.
	

04
	CAMPAÑAS & NEWSLETTERS
Motor de email marketing propio. Segmentación de listas, editor drag-and-drop, programación, analytics de apertura/clic y tests A/B con IA.
	

05
	BANDEJA UNIFICADA
Inbox centralizado que agrega WhatsApp Business, correo, Facebook Messenger e Instagram DM. Respuestas asistidas por IA con contexto del CRM.
	

06
	CLIENTES & CONTACTOS
Base de datos de prospectos y clientes con historial completo, etiquetas, segmentación dinámica y score de salud de relación generado por IA.
	

07
	ANALÍTICA & REPORTES
Dashboard de métricas: tasa de conversión, valor de pipeline, ROI de campañas, actividad por agente. Reportes automáticos semanales por correo.
	

08
	ADMINISTRACIÓN & ACCESOS
Gestión de usuarios, roles (Admin, Vendedor, Consultor), integraciones API, webhooks, configuración de automatizaciones y auditoría de acciones.
	

3. SUPERPODERES IA — AGENTES COGNITIVOS


El HUB integra una capa de agentes de IA construidos sobre el ADK Agent Framework (Google) con memoria en LanceDB y orquestación secuencial/paralela. Cada agente tiene un dominio específico y puede ser activado manualmente o por trigger automático.


3.1 Agente SCOUT — Calificador de Prospectos
* Analiza el perfil de un nuevo lead (industria, tamaño, comportamiento, mensajes iniciales) y asigna un score de 0–100 con justificación.
* Propone etiquetas automáticas y sugiere el vendedor más adecuado para atenderlo.
* Detecta señales de compra en conversaciones y alerta en tiempo real.
* Tecnología: Claude claude-sonnet-4-20250514 + LanceDB para memoria vectorial de perfiles anteriores


3.2 Agente REDACTOR — Generación de Contenido
* Redacta propuestas de cotización completas a partir de los parámetros del proyecto (tipo, materiales, plazos, presupuesto).
* Genera newsletters personalizados por segmento con tono y voz de marca de Desarrollos Elaborados o iAprende.
* Produce variantes A/B de asuntos de email y calls-to-action optimizados.
* Tecnología: Claude claude-sonnet-4-20250514 + plantillas en Markdown + PDF renderer


3.3 Agente NEXO — Bandeja Unificada Inteligente
* Lee mensajes entrantes de todos los canales y los clasifica por intención (cotización, soporte, queja, interés en curso).
* Redacta respuestas sugeridas con contexto del historial CRM del contacto.
* Escala automáticamente a humano cuando detecta urgencia o queja crítica.
* Tecnología: WhatsApp Business API + IMAP/SMTP + Claude con function calling


3.4 Agente ESTRATEGA — Scoring de Ideas y Proyectos
* Evalúa ideas internas con una matriz de criterios: potencial de ingreso, alineación con Manufactura Cognitiva, recursos necesarios, tiempo al mercado.
* Genera un reporte ejecutivo de 1 página por idea con recomendación Go / No-Go / Validar.
* Compara ideas entre sí y propone roadmap priorizado trimestral.
* Tecnología: Claude + structured outputs JSON + Supabase para persistir evaluaciones


3.5 Agente ANALISTA — Insights Automáticos
* Genera resúmenes ejecutivos de pipeline cada lunes a las 8 AM: deals en riesgo, oportunidades calientes, cuellos de botella en embudo.
* Detecta anomalías (caída en tasa de apertura, silencio prolongado de cliente clave) y envía alertas.
* Crea reportes narrativos en lenguaje natural listos para compartir con stakeholders.
* Tecnología: Firebase Functions (cron) + Claude + SendGrid / Resend para entrega


3.6 Agente CAMPANERO — Automatización de Campañas
* Planifica calendarios de campañas basados en historial de engagement y fechas clave (temporadas, lanzamientos).
* Segmenta listas dinámicamente según comportamiento reciente (abrió email, visitó propuesta, no respondió en 7 días).
* Sugiere el mejor horario y día de envío por segmento basándose en datos históricos.
* Tecnología: Resend / Loops + Claude para planeación + cron jobs en Cloud Run


4. FUNCIONES CLAVE POR MÓDULO


4.1 Pipeline CRM
* Vista Kanban drag-and-drop con columnas configurables por tipo de negocio
* Filtros inteligentes: por valor, probabilidad, fecha de cierre, etiqueta, vendedor
* Historial de actividad cronológico (llamadas, emails, propuestas, notas)
* Recordatorios automáticos de follow-up con delay configurable
* Templates de secuencias de seguimiento (Día 1, Día 3, Día 7…)
* Integración con calendario para agendar demos o reuniones directamente desde el deal


4.2 Generador de Cotizaciones
* Formulario paramétrico: tipo de servicio, materiales, dimensiones, plazo, condiciones
* Cálculo automático con márgenes configurables por categoría
* PDF profesional con branding de Desarrollos Elaborados generado al instante
* Envío directo por email desde el HUB con tracking de apertura
* Versioning: v1, v2… con historial de cambios y comparación
* Firma digital básica (checkbox de aceptación con timestamp)


4.3 Campañas & Newsletter
* Editor visual tipo drag-and-drop (bloques: texto, imagen, CTA, separador, video embed)
* Listas de contactos con importación CSV/Excel y sincronización automática desde CRM
* Segmentación por etiquetas, etapa del funnel, industria, comportamiento previo
* Tests A/B en asunto, contenido o CTA con winner automático
* Analytics en tiempo real: tasa de apertura, CTR, rebotes, bajas
* Automatizaciones: bienvenida, nurturing, re-engagement, post-cotización


4.4 Bandeja Unificada
* Inbox unificado con pestañas: WhatsApp / Email / Facebook / Instagram
* Asignación de conversaciones a agentes del equipo
* Respuestas rápidas predefinidas con variables dinámicas ({{nombre}}, {{empresa}})
* Etiquetado automático de conversaciones por intención detectada por IA
* Modo 'fuera de oficina' con respuesta automática contextual
* Vista de contacto lateral con historial CRM completo al responder


5. STACK TECNOLÓGICO


El stack está diseñado para máxima velocidad de desarrollo, mínimo costo operativo en Fase 1, y escalabilidad hacia SaaS multi-tenant en Fase 2. Se prioriza compatibilidad con el ecosistema ya existente de Desarrollos Elaborados (Firebase, Mac Mini M4, Clawdbot).


CAPA
	TECNOLOGÍA / JUSTIFICACIÓN
	Frontend
	Next.js 14 (App Router) + TypeScript + Tailwind CSS + shadcn/ui — SSR para SEO, componentes accesibles, deploy en Vercel.
	Backend / API
	Next.js API Routes + tRPC para type-safety extremo entre front y back. Alternativa ligera: Hono.js en Cloudflare Workers.
	Base de datos
	Supabase (Postgres) como base principal — RLS para multi-tenant, realtime subscriptions para el Inbox. Firebase como fallback/ya existente.
	Autenticación
	Supabase Auth + NextAuth.js — soporta Google OAuth, magic link y credenciales. Roles por JWT.
	IA / Agentes
	Anthropic Claude claude-sonnet-4-20250514 vía API + Google ADK SequentialAgent para orquestación. LanceDB local en Mac Mini M4 para memoria vectorial.
	Email & Campañas
	Resend (transaccional) + Loops.so o listmonk self-hosted (newsletters masivos). React Email para plantillas.
	Mensajería
	WhatsApp: Meta Cloud API (WABA). Facebook/Instagram: Graph API. Websockets para inbox en tiempo real.
	Storage
	Supabase Storage (archivos adjuntos, PDFs de cotización). Cloudinary para imágenes en campañas.
	PDF / Docs
	Puppeteer / Playwright headless para generar PDFs de cotizaciones con branding. Plantillas en HTML+CSS.
	Hosting
	Vercel (frontend + API) + Supabase Cloud. Opción on-premise: Mac Mini M4 con Docker Compose para agentes IA.
	Monitoreo
	Sentry (errores frontend/backend) + Logflare/Axiom (logs). PostHog para analytics de uso interno.
	CI/CD
	GitHub Actions → Vercel deploy automático. Environments: dev / staging / prod.
